# AI/ML Foundations: From Regression to Decision Trees

A beginner-friendly, 4-week guided project that introduces the core ideas of machine learning. Mentees learn how common algorithms work and apply them in Python.

## Motivation

Machine learning powers everything from movie recommendations to medical diagnosis, but getting started can feel overwhelming. This project offers a structured path that builds intuition for the mathematics behind the models, so you understand what your code is doing instead of just calling library functions.

## Prerequisites

- Basic probability
- Basic linear algebra (vectors, matrices)
- Basic calculus (derivatives, gradients)
- Familiarity with Python (NumPy and Pandas can be learned along the way)
- Interest in machine learning; no prior ML experience needed

**Time commitment:** 5–7 hours per week

## Week-wise plan

| Week | Topics | Hands-on | Material |
|---|---|---|---|
| 1 | Optimization, linear regression, gradient descent | NumPy primer, line fitting | [Week 1](week-1/README.md) |
| 2 | Stochastic gradient descent, MAP estimation, bias-variance tradeoff, Ridge and LASSO, naive Bayes | Overfitting with and without regularization | Coming soon |
| 3 | Logistic regression, multiclass classification, perceptron, decision trees | Start the final project | Coming soon |
| 4 | Revision and doubt solving | Finish and present the final project | Coming soon |

## Final project: Titanic survival prediction

Using the [Kaggle Titanic dataset](https://www.kaggle.com/competitions/titanic), mentees will:

1. Explore and clean the data
2. Train logistic regression, naive Bayes and decision tree classifiers
3. Compare the models on data held out from training
4. Present their findings

**Deliverables:** a notebook with the code and results, and a short presentation.

## Expected outcomes

By the end of the project, you will be able to:

- Explain the fundamental machine learning algorithms
- Choose a suitable model for a simple problem
- Train and evaluate models in Python
- Recognize overfitting and reduce it
